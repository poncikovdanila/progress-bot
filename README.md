# Бот-трекер привычек

## Шаг 1. Получить токен у @BotFather

1. Открой Telegram, найди **@BotFather**.
2. Отправь `/newbot` (или используй уже существующего бота — тогда `/token` в @BotFather, чтобы получить токен заново).
3. Придумай имя и username (username обязательно должен заканчиваться на `bot`).
4. @BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Сохрани его — это `BOT_TOKEN`.

## Шаг 2. Запуск локально

```bash
cd progress_bot
pip install -r requirements.txt
export BOT_TOKEN="твой_токен_сюда"
python bot.py
```

В консоли должно появиться `Бот запущен`. В Telegram напиши своему боту `/start` — он ответит и покажет твой `chat_id`.

Чтобы получать *автоматические* утренние/вечерние напоминания (а не только отвечать на команды), останови бота (Ctrl+C), задай ещё и `CHAT_ID`, и перезапусти:

```bash
export CHAT_ID="твой_chat_id_из_/start"
python bot.py
```

Проверь команды: `/start`, `/habits`, `/tasks`, `/progress`.

## Шаг 3. Деплой на Render (чтобы бот работал 24/7, а не только пока открыт терминал)

1. Залей эту папку в свой репозиторий на GitHub (см. ниже).
2. На [render.com](https://render.com) → **New** → **Background Worker** (не Web Service — боту не нужен публичный HTTP-порт).
3. Подключи свой GitHub-репозиторий.
4. **Build command:** `pip install -r requirements.txt`
5. **Start command:** `python bot.py`
6. В **Environment** добавь переменные:
   - `BOT_TOKEN` — токен из шага 1
   - `CHAT_ID` — твой chat_id из `/start`
7. Deploy.

⚠️ На бесплатном тарифе Render файловая система эфемерная — `data.json` (лог привычек) может обнулиться при передеплое/рестарте контейнера. Для личного использования это не критично, но имей в виду.

## Как добавить/изменить привычки

Больше не нужно лезть в код и передеплоивать — привычки хранятся в `data.json` и правятся прямо из чата с ботом:

- `/addhabit <цель_в_неделю> <название>` — добавить, например `/addhabit 4 Чтение`
- `/sethabit <id> <новая_цель>` — поменять недельную цель
- `/removehabit <id>` — удалить (id привычки видно в подсказках команд выше)

`tasks.py` со списком `HABITS` используется только один раз — как стартовый набор при самом первом запуске (если `data.json` ещё пустой). После этого вся правда о привычках живёт в `data.json`.

Разовые задачи с дедлайном (`TASKS`) пока остаются в `tasks.py` — их не так часто меняют.

## Структура проекта

- `bot.py` — точка входа, команды и напоминания
- `tasks.py` — конфигурация привычек и задач
- `storage.py` — сохранение прогресса в `data.json`
- `requirements.txt` — зависимости

## Mini App

Помимо текстовых команд, есть страница-приложение (`webapp/index.html`) с прогресс-барами и кнопками — открывается прямо внутри Telegram по команде `/app`.

Технически это отдельный маленький веб-сервер (`webapp_server.py`, на Flask), который запускается вторым потоком внутри того же `bot.py`. Он отдаёт саму страницу и два API-эндпоинта (`/api/habits`, `/api/log`), защищённых проверкой подписи `Telegram.WebApp.initData` — так что дёрнуть их может только настоящий Mini App, открытый из Telegram у тебя же в аккаунте.

**Важно:** Telegram открывает Mini App только по настоящему https-адресу. На `localhost` кнопка `/app` работать не будет — нужен деплой.

### Как задеплоить с Mini App

1. На Render это должен быть **Web Service** (не Background Worker, как раньше) — потому что теперь нужен открытый порт для веб-страницы и API.
2. **Build command:** `pip install -r requirements.txt`
3. **Start command:** `python bot.py`
4. Переменные окружения:
   - `BOT_TOKEN`
   - `CHAT_ID`
   - `WEBAPP_URL` — заполняется **после** первого деплоя, когда узнаешь свой адрес на Render (вида `https://твой-сервис.onrender.com/webapp`). Задеплой один раз без неё, посмотри адрес сервиса, добавь переменную и передеплой ещё раз.
5. Render сам передаёт порт через переменную `PORT` — `webapp_server.py` уже её использует, ничего менять не нужно.

### Как посмотреть вёрстку локально (без Telegram)

Просто открой `webapp/index.html` в браузере — вёрстку увидишь, но данные не загрузятся (Telegram-объект и initData доступны только внутри самого Telegram). Для проверки реальной работы — только через задеплоенный `/app` в самом боте.
